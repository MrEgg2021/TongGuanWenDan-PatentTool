# CNIPA 双预览环境

轻量预览需要安装并启动官方预览插件，仅支持四书；本工具调用已运行的轻量预览服务（默认端口 `8080`），不启动或关闭该外部服务。

## 全量预览服务：使用已安装客户端

用户必须自行安装专利业务办理系统客户端（CNIPA）。没有记录路径时，程序自动检查卸载注册表和固定磁盘下精确的 `Program Files/CNIPAClient`、`Program Files (x86)/CNIPAClient`，不递归扫描磁盘。检测不到会提示“没有检测到已安装的专利业务办理系统客户端（CNIPA），暂无法使用全量预览”，提供 `重新检测` 和 `选择客户端目录…`。设置入口为 `全量预览服务 → 检测/选择路径`。

验证成功的安装目录保存在用户设置 `cnipa_runtime_source_v1` 中。后续先使用该路径，不重复扫描注册表或磁盘；跨会话首次使用会检查该目录。会话内只对已知 Java、classpath 配置和 JAR 文件检查大小及修改时间。组件变化时重新检查并重启渲染进程；文件缺失或组件加载失败时提示重新检测或选择。普通案卷内容错误不清除可用路径。

重新检测或选择相同目录且组件签名未变化时，保留已经加载的渲染进程；只有目录或组件变化才停止旧进程并重新预热。

全量预览界面只支持检测或选择已安装客户端，不提供运行时 ZIP 归档导入、复制或自动下载入口。案卷 ZIP 输入保持不变。

## 文件和进程边界

`InstalledLibraryManager` 从安装目录读取 Java 和按 Wrapper classpath 顺序排列的 JAR，通过本工具生成的小型 classpath manifest 加载。只读取 `wrapper.conf` 中的库路径，不加载安装目录的配置目录，不启动 Wrapper、Spring、官方应用或数据库。

进程工作目录、Groovy 脚本、classpath launcher、输出和 Java 临时目录均在 `get_user_data_dir()/preview-work/session-*`；标准输出日志保留在本工具进程内存。案卷由现有安全解包流程放入独立临时目录。所有请求路径使用正斜杠，满足官方模型在 Windows 上的路径解析要求。不要把工作路径、`cpc.home`、`cpc_path` 或 `java.io.tmpdir` 指向官方安装目录。

应用界面构建后会安排后台检查客户端并预热一个最小 JVM，通过官方 `ModelFactory.saveToPDF` 处理主 XML 和可选的 `section_1.xml`，无需启动整套 HTTP 服务。预热与渲染串行，共用同一个进程；切页和最小化到托盘不会停止它。真正退出程序、取消正在执行的渲染或渲染超时会终止并等待本工具的子进程，清理本次工作目录。取消和超时后下次任务重新加载，不发布中断任务的半成品。

预览页分别显示轻量 HTTP 服务连接与全量组件就绪状态，设置页同步显示；客户端目录、端口与失败详情在悬停提示中查看。轻量连接每 5 秒后台检查，全量进程状态每秒刷新，不因刷新重复启动渲染器。启动检测失败只更新状态，不弹出预览阻塞框；可在设置中重新检测，成功后自动预热。任务进度按实际加载或复用状态提示。

客户端组件在渲染期间变化时丢弃本次结果，提示等更新完成后重试。客户端升级改变结构或 API 时仍可能需要修复适配，不保证所有未来版本兼容。

## 代码集查询

请求书类文书（如 `110101` 发明专利请求书）的表单含代码集字段，官方渲染库通过 HTTP 查询代码集，把 `CN`、`330000` 换成 `中国`、`浙江省`。库的默认查询地址由属性 `ecloud.service.base` 指定，可能无法在用户环境中访问；本工具为其选择可用的本机端点。

本工具在启动渲染进程前解析该地址：只从官方客户端的 `plugins/as/cpc-main-as/conf/application.yml` 读取 `server.port` 与 `xml2pdf-plugin.codeset.base-path` 两个标量，得到客户端自己运行时的本机服务地址。只读该文件的这两个标量，不启动客户端、不加载官方整套配置、不改写该文件，端口也不写死（客户端升级后端口或路径变化时按新声明使用）。随后用 1 秒超时探测 `GET <base>?codeType=GUOBIE&code=CN`（直连本机，不经系统代理）是否返回文本：可用就把该地址作为 `-Decloud.service.base` 传给渲染进程；配置缺失、不可解析或探测失败时改用下节的自带码表端点。两种情况都加 `-Dsun.net.client.defaultConnectTimeout=1500`、`-Dsun.net.client.defaultReadTimeout=5000`，单次查询等待不超过约 2 秒。只接受本机 loopback 地址。

### 自带码表端点

官方客户端的服务不可达时，本工具自己起一个极小 HTTP 服务顶替它，使请求书类文书的国别与省市仍显示中文名称，不必要求用户开着官方客户端：

- 只绑 `127.0.0.1` 与系统分配的临时端口，不绑 `0.0.0.0`，不占用官方客户端声明的端口；只处理渲染库实际调用的那一个路径 `GET /public-base/codeset/findByCode`（参数 `codeType`、`code`），返回纯文本名称。
- 只在本次程序运行期间存在，作为守护线程随渲染进程生命周期复用，真正退出程序时关闭，不留下监听端口或后台线程。
- 覆盖范围：国别 `GUOBIE` 用随程序分发的常用国家/地区中文简称资源 `resources/codeset_local_guobie.json`；省市 `SHENG`、`SHI` 用仓库既有的全国行政区划数据 `core/regions_cn.py`（含直辖市“市辖区”码）。
- 需要官方登记数据的字段（如代理机构 `DLJGDM`，只能由所名反查机构代码）以及自带表未覆盖的类型、查不到的代码，一律按原值返回，不编造、不猜测、不机翻。
- 不读取官方加密数据库，不复制官方登记数据，不修改官方安装目录任何文件，也不向任何外部地址发送查询或接收数据。

自带码表在本机内存中查询。

### 端点来源与生命周期

端点选择顺序是“官方客户端服务优先，其次自带码表”，只有两者都不用时才回落到一个必定快速失败的本机地址。来源或端点只在渲染进程启动时确定，所以客户端启停导致选择变化时，本工具会停止并重建渲染进程以采用新端点；来源不变时继续复用同一进程。客户端未运行时请求书类文书仍正常渲染：国别与省市显示为中文名称，代理机构代码等官方登记字段显示原值，预览页会说明这一范围；打开官方客户端后重新生成即可获得最完整结果。两种来源都不可用时仍保留原有的不可用提示。

轻量预览与无清单四书不受影响：轻量预览仍只有四书；没有 list.xml 时仍只识别 `100001.xml`～`100004.xml`。说明书、附图的图片渲染耗时仍取决于文档内容。

## 文书范围

“全量”指按照 `list.xml` 读取完整文件清单并逐项尝试，不表示每种官方文书均已实测。保留勾选、拖动顺序、单项错误和本地合并导出。多个 `section_*.xml` 的未验证结构明确报错，避免遗漏附页。

意见陈述书 `100012` 支持 ZIP 中附页和同目录图片；只采用 ZIP 内容，不补入官方客户端数据库中的代理机构信息。

## 构建边界

EXE 不包含官方运行时 ZIP，GUI 不提供运行包入口。运行包构建脚本仅用于离线诊断。PyInstaller 数据完整性门禁拒绝被引用的 Git LFS 指针文件。

## 无清单四书与直接保存

全量预览无需轻量插件：没有 list.xml 时识别 100001.xml～100004.xml，支持四书子集及图片相对路径。有清单则以清单为准；不根据自定义文件名猜测未知表单。

有清单时逐项按文件内容分类：内容是 XML 的交给官方渲染器；内容是 PDF 的不渲染，直接把原文件按当前顺序并入预览与合并导出，新版客户端作为已签字附件放入案卷包的“总委托书”等即属于这一类；内容是图片的先转为 PDF 再并入。真实后缀次之，清单的 `GESHILX` 只作提示。非 XML 条目不需要 `BIAOGEDM`，显示名取 `WENJIANMC`，缺失时回退文件名。附件不经过官方渲染器，解析、排序和“只勾选附件”生成 PDF 都不会启动渲染进程。无法识别内容的附件只把该项标为失败并给出原因，其它文件照常。

轻量预览仍只有四书，不包含附件。没有 list.xml 的包仍只识别 100001.xml～100004.xml，包内附件不会并入；多个 `section_*.xml` 的未验证结构仍明确报错。

第一次打开的 PDF 保存到应用临时目录，文件名由案卷名加 `_预览.pdf` 自动生成。选择“另存预览 PDF”时可在系统保存对话框中直接输入所需文件名；应用不会保存或套用 PDF 命名规则。

“另存预览 PDF”复制已经生成的 PDF；也可以在阅读器直接另存。可通过勾选选项生成单独文书 PDF。重复打开使用已有结果，拖动排序只重新合并，新勾选文件只生成缺少的 PDF。新修订使用独立目录，避免阅读器锁住旧文件；全部选中项成功后才打开或保存，失败项可以重试或取消勾选。源 ZIP 变化后重新解析，渲染中变化则拒绝本次结果。

## 运行验证

运行 `python gui_app.py`，在“设置 → 全量预览服务”检测或选择已安装客户端目录，从预览页载入测试案卷并执行渲染。检查文书清单、选中项生成结果、合并 PDF、另存和退出后的自有进程清理，记录实际环境和结果。

渲染耗时受官方组件、文书页数、图片数量和内存影响，不承诺固定完成时间。源码检查、单元测试和自动截图不能替代实际预览验证。
