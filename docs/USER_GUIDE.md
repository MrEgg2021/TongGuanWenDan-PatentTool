# 通官文旦-专利工具用户手册

适用版本：V1.0.0

通官文旦-专利工具用于专利文档转换、官文整理及相关材料处理，全部功能免费使用，无需激活。

## 运行前准备

使用 Windows 10/11。程序下载与安装步骤见 [README 的「下载与安装」](../README.md#下载与安装)：下载 `.exe` 后双击即可运行，无需安装。源码运行按 [README 的「从源码运行」](../README.md#从源码运行) 建立 Python 环境并启动 `gui_app.py`。

Word 转档需要 Microsoft Word。先保存原稿并关闭待转换文档，按环境检测提示处理 Office 占用。转换会使用 Word 和剪贴板，运行期间避免操作它们。建议先用一份脱敏文档确认环境和输出。

PDF 预览需要相应官方软件，详见 [预览环境](CNIPA_PREVIEW_RUNTIME.md)。

## Word 转 XML / 案卷包

1. 在国内申请转档中选择单文档或批量处理，加入 Word 文件。
2. 选择专利类型、转换范围及输出目录，按提示检查必要章节和请求书信息。
3. 开始转换，等待任务结束；批量任务逐项查看成功和失败结果。
4. 打开输出目录，核对生成的 XML、案卷 ZIP 和预览，重点检查图片、公式、表格及章节顺序。

原稿应保留备份。缺少章节或环境检查失败时，按提示修正文档或环境后重新转换；输出位置和结果以软件实际显示为准。

## 请求书与常用信息

填写申请人、发明人等请求书信息，核对必填项后保存或继续转换。常用信息管理支持导入、编辑、删除、保存、全量及脱敏导出；请求书可使用下拉候选与联动预填。

编辑列表后点击保存才会写入数据库。数据库路径在数据管理页设置，应选择本地可写目录。操作前可导出备份，避免多个程序实例同时写入同一数据库。

## 官文处理

加入官方通知书 ZIP，检查解析出的申请信息与文书清单，设置 PDF 命名、输出位置及归档选项后执行。

归档会改变原始文件位置，执行前确认规则。完成后逐项检查 PDF、Excel 记录和归档结果；无法识别或处理失败的子件按提示单独处理，部分成功不代表整批完成。

## 形式审查

选择文档和审查范围后开始。词库默认使用“精简默认”，可在设置中切换。检查结果可用于定位、忽略或写回，仍需人工核对。

写回前保留文档备份，按提示避免手工编辑。伴侣模式重新审查前会进行“文档状态检查”，请根据提示清理批注、接受修订、关闭修订模式并保存。

## 答复与补正

选择答复、补正或相应主动处理入口，导入通知书及相关文档，核对申请信息、通知书类型和文件清单后生成材料。

运行时遵循 Word 环境与进度提示，完成后核对生成文件。界面未提供安全取消的任务，应等待结束再退出。

## PDF 预览与环境检测

在设置中选择预览模式，并查看服务状态：

- 轻量预览（legacy）使用已启动的官方预览插件服务，默认端口为 `8080`，支持四书。
- 全量预览（full）通过“检测/选择路径”读取已安装的专利业务办理系统客户端组件，支持的文书范围由案卷和官方组件决定。

全量模式不改动官方安装目录，不代为下载外部软件。载入案卷后检查文书清单，选择预览内容；全部选中项成功后才打开或保存合并 PDF。失败项可重试或取消勾选。“另存预览 PDF”保存已生成的结果，可在保存对话框中修改文件名。

详细环境要求和文件处理边界见 [CNIPA 双预览环境](CNIPA_PREVIEW_RUNTIME.md)。

## 设置与关于

设置修改后点击保存，普通偏好存储在 `user_prefs.json`。保存失败会保留原设置和当前编辑，请按提示处理后重试；离开页面时选择“不保存”会恢复已保存值。环境检测可帮助定位 Word 与预览环境问题。

遇到问题时先记录版本、操作步骤和错误提示。运行日志写入程序目录下的 `conversion.log`；程序目录不可写时写入用户数据目录 `%APPDATA%\CPC-XML-Converter\conversion.log`，可自行查看，日志不会上传。

关于页显示当前版本、免费开源信息、作者和联系方式。点击“开源许可与第三方声明”，默认查看中文许可说明，也可切换到中文第三方声明或 AGPL 英文原文；中文说明仅供阅读参考，许可条件以原文为准。点击“查看更新日志”查看版本说明。

许可为 AGPL-3.0-only。仅使用本程序不产生开源义务：日常使用、在机构内部多台电脑部署或接入内部工作流，都不需要公开你的文档或内部系统；程序离线运行，不上传任何数据。只有修改程序后对外分发，或将修改版作为对外服务提供时，才需要按许可证提供对应源码。源码获取方式见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 问题反馈

遇到问题时先查阅本手册，并查看程序目录下的 `conversion.log`（程序目录不可写时为 `%APPDATA%\CPC-XML-Converter\conversion.log`）；也可在项目 Issues 中搜索或提问，附上版本、复现步骤和错误提示。
